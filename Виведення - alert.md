# Виведення - alert

## 🧩 Теоретичний матеріал

Команда `alert` показує повідомлення у спливаючому вікні браузера. Її можна використати, коли потрібно, щоб текст побачив звичайний відвідувач сторінки, а не лише той, хто дивиться в консоль.

***Приклад:***
```javascript
alert("Привіт, світе!")
```
***Результат у спливаючому вікні браузера:***
```
Привіт, світе!
```

У цьому прикладі `alert` отримує один аргумент - рядок `"Привіт, світе!"`. Коли JavaScript виконує цю команду, браузер показує у *спливаючому вікні* все, що знаходиться в лапках.

### Відмінність від console.log

`console.log` робить виведення в консоль. Це зручно під час перевірки програми, але звичайний відвідувач сторінки цього тексту не бачить.

`alert` робить виведення на екран: браузер відкриває вікно з повідомленням. Таке вікно бачить користувач, і воно зупиняє роботу програми, доки його не закриють.

## 🎯 Практичне завдання

Напиши програму, яка показує у вікні браузера привітання для себе. Використай `alert` і підстав своє ім'я замість прикладу.

Наприклад, у вікні повинно бути показано:
```
Привіт, Євген!
```
