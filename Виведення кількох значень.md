# Виведення кількох значень

## 🧩 Теоретичний матеріал

Одним викликом `console.log` можна вивести одразу кілька значень. Для цього потрібно записати у дужках кілька аргументів, розділивши їх комами. У виведенні значення будуть розділені пробілами.

***Приклад:***
```javascript
console.log("Привіт,", "Оля!")
```
***Результат у консолі:***
```
Привіт, Оля!
```

У цьому прикладі два аргументи: `"Привіт,"` і `"Оля!"`. Між ними JavaScript ставить пробіл, тому слова не злипаються.

## 🎯 Практичне завдання

Напиши програму, яка виводить у консоль привітання для себе командою `console.log`.

⚠️ Передай кілька аргументів, розділених комами. Не збирай увесь текст в один рядок.

Наприклад, у консолі повинно бути надруковано:
```
Привіт, Євген!
```
