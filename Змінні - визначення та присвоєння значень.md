# Змінні - визначення та присвоєння значень

## 🧩 Теоретичний матеріал

Іноді в коді варто дати значенню **ім'я**. Тоді легше зрозуміти, що означає число чи рядок, крім того, те саме значення можна використати кілька разів, не копіюючи його.

Таке ім'я називають ***змінною***. 

Перед використанням змінну потрібно ***визначити***. Визначення змінної записують ключовим словом `let`, далі вказують ***ім'я змінної***, знак `=` і ***значення змінної***.

⚠️ Знак `=` тут означає ***присвоєння***: "зберегти значення у змінній", а не "рівність" з математики.

***Приклад:***
```javascript
let city = "Київ"
console.log(city)
```
***Результат у консолі:***
```
Київ
```

Коли JavaScript бачить ім'я змінної, він підставляє збережене значення.

Якщо значення потрібне кілька разів, змінна дозволяє записати його один раз і далі лише звертатися до значення за ім'ям:

***Приклад:***
```javascript
let ticketPrice = 80
console.log("Квиток:", ticketPrice, "грн")
console.log("Два квитки:", ticketPrice * 2, "грн")
```
***Результат у консолі:***
```
Квиток: 80 грн
Два квитки: 160 грн
```

Якщо ціна зміниться, достатньо виправити `80` в одному місці - усі виведення, що використовують `ticketPrice`, використають нове значення.

## 🎯 Практичне завдання

> ***Індекс маси тіла*** (***ІМТ***) показує, наскільки маса людини відповідає її зросту. Його рахують так: масу (`m`) в кілограмах ділять на зріст (`h`) у метрах, помножений сам на себе:
> 
> <p><i>ІМТ</i> = <i>m</i> / <i>h</i><sup>2</sup></p>
>
> Середня маса людини - близько `62`кг. Типовий зріст - `1.7`м.

В JavaScript ІМТ для людини з середніми параметрами можна порахувати так:

```javascript
console.log("ІМТ:", 62 / (1.7 * 1.7))
```

1. Збережи масу і зріст у змінних і використай ці змінні у формулі ІМТ.
2. Зміни значення росту на `1.6`

У консолі має з'явитися текст:
```
ІМТ: 24.218749999999996
```
