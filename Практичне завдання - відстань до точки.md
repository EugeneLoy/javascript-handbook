# Практичне завдання - відстань до точки

## 🧩 Теоретичний матеріал

Іноді в коді варто дати значенню **ім'я**. Тоді легше зрозуміти, що означає число, і те саме значення можна використати кілька разів.

Таке ім'я називають ***змінною***. Перед використанням змінну потрібно ***визначити***: записати ключове слово `let`, далі ***ім'я змінної***, знак `=` і ***значення змінної***.

⚠️ Знак `=` тут означає ***присвоєння***: "зберегти значення у змінній".

***Приклад:***
```javascript
let x = 8
console.log(x)
console.log(x * x)
```
***Результат у консолі:***
```
8
64
```

Коли JavaScript бачить ім'я змінної, він підставляє збережене значення. Якщо змінити `8` на інше число, обидва виведення використають нове значення.

## 🎯 Практичне завдання

На координатній площині задано точку з координатами `(x, y)`. Потрібно порахувати відстань від початку координат `(0, 0)` до цієї точки.

Цю відстань рахують за теоремою Піфагора.

Доповни стартовий код. Використай змінні `x` і `y` у виразі, щоб програма працювала **для будь-яких** їхніх значень, а не лише для `3` і `4`.

```javascript
let x = 3
let y = 4

// ❗ Порахуй та виведи відстань від початку координат до точки з координатами (x, y).

```

⚠️ Обов'язково запиши вираз з використанням `Math.sqrt` і змінних `x` та `y`. Не рахуй результат вручну і не підставляй у виведення готове число.

Якщо `x` має значення `3`, а `y` - `4`, у консолі має з'явитися:
```
5
```

Якщо `x` має значення `5`, а `y` - `12`, у консолі має з'явитися:
```
13
```
