# Теоретична частина

_Логічна помилка_ виникає, коли програма запускається, але робить не те, що задумано. На відміну від синтаксичної помилки, JavaScript не показує повідомлення: з його погляду команди записані правильно. Тому такі помилки складніше помітити.

Типи значень тут особливо важливі. Оператор `+` працює по-різному залежно від типів операндів: для чисел це додавання, для рядків - конкатенація. Якщо змішати рядок і число, JavaScript обирає склеювання: число стає текстом і "приклеюється" до рядка.

***Приклад:***
```javascript
console.log(120 + 30)
console.log("120" + 30)
```
***Результат у консолі:***
```
150
12030
```

У першому рядку обидва операнди - числа, тож `+` додає числа `120` і `30`. У другому рядок `"120"` записаний у лапках, тому JavaScript склеює `"120"` і `"30"` у `"12030"`. Програма виконалась без помилки, але результат може бути не таким, який очікував розробник, якщо потрібна була саме сума.

# Практичне завдання

У програмі нижче два вирази дають неочікуваний результат, бо типи операндів не відповідають задуму.

1. Перший вираз мав додати числа `18` і `7`.
2. Другий вираз мав склеїти текст `"9"` і `"6"` (наприклад, номер кабінету).

Виправ кожен вираз.

```javascript
console.log("18" + 7)
console.log(9 + 6)
```

Після виправлення у консолі має з'явитися такий текст:

```
25
96
```
