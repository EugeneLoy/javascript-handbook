# Теоретична частина

Якщо у виразі кілька операторів, JavaScript спочатку виконує операції з вищим _пріоритетом_. Пріоритет такий самий, як у звичайній математиці: множення `*` і ділення `/` виконуються раніше, ніж додавання `+` і віднімання `-`.

***Приклад:***
```javascript
console.log(2 + 3 * 4)
```
***Результат у консолі:***
```
14
```

Спочатку множиться `3 * 4`, потім додається `2`.

Дужки змінюють порядок: те, що в дужках, обчислюється першим.

***Приклад:***
```javascript
console.log((2 + 3) * 4)
```
***Результат у консолі:***
```
20
```

Спочатку додаються `2` і `3`, потім сума множиться на `4`.

# Практичне завдання

Використай JavaScript як калькулятор: порахуй площу трапеції.

1. Знайди формулу площі трапеції в інтернеті.
2. Підстав у вираз такі значення: основи `8` і `12`, висота `5`.
3. Виведи результат однією командою `console.log` (обов'язково використай вираз для обчислення результату).

У консолі має з'явитися такий текст:

```
50
```
