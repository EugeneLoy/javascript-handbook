# Введення - `prompt`

## 🧩 Теоретичний матеріал

Функція `prompt` запитує дані у користувача під час роботи програми. Під час виклику браузер покаже спливаюче вікно з текстом-підказкою і полем для введення. Програма почекає, доки користувач введе значення і натисне OK.

Аргумент `prompt` - це підказка: вона пояснює користувачу, що саме потрібно ввести.

`prompt` повертає введене значення, яке часто зберігають у змінну, щоб потім використати в програмі.

***Приклад:***
```javascript
let name = prompt("Введіть ім'я:")
alert("Привіт, " + name + "!")
```
Якщо користувач введе `Євген`, у спливаючому вікні `alert` з'явиться:
```
Привіт, Євген!
```

⚠️ `prompt` завжди повертає **рядок** тексту, навіть якщо користувач ввів цифри. 

## 🎯 Практичне завдання

На координатній площині задано точку з координатами `(x, y)`. Порахуй відстань від початку координат `(0, 0)` до цієї точки.

Доповни стартовий код. Замість готових чисел запитай у користувача значення `x` і `y` за допомогою `prompt`.

```javascript
// ❗ 1. запитай у користувача значення x і збережи його у змінну як число
let x = 3
// ❗ 2. запитай у користувача значення y і збережи його у змінну як число
let y = 4

console.log(Math.sqrt(x * x + y * y))
```

⚠️ `prompt` повертає **рядок**. Перед обчисленнями перетвори введене значення на число за допомогою `Number`.

⚠️ Рядок з `console.log` залиш без змін.

Якщо користувач введе `3`, а потім `4`, у консолі має з'явитися:
```
5
```

Якщо користувач введе `5`, а потім `12`, у консолі має з'явитися:
```
13
```
