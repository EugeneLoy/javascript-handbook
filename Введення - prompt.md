# Введення - `prompt`

## 🧩 Теоретичний матеріал

Команда `prompt` запитує дані у користувача під час роботи програми. Браузер показує спливаюче вікно з текстом-підказкою і полем для введення. Програма чекає, доки користувач введе значення і натисне OK.

Аргумент `prompt` - це підказка: вона пояснює користувачу, що саме потрібно ввести.

`prompt` повертає введене значення, яке часто зберігають у змінну, щоб потім використати в програмі.

***Приклад:***
```javascript
let name = prompt("Введіть ім'я:")
alert("Привіт, " + name + "!")
```
Якщо користувач введе `Євген`, у спливаючому вікні `alert` з'явиться:
```
Привіт, Євген!
```

⚠️ `prompt` завжди повертає **рядок** (`string`), навіть якщо користувач ввів цифри. Для обчислень рядок потрібно перетворити на число командою `Number`.

***Приклад:***
```javascript
let age = Number(prompt("Введіть вік:"))
alert("Наступного року вам буде " + (age + 1))
```
Якщо користувач введе `14`, у вікні `alert` з'явиться:
```
Наступного року вам буде 15
```

Без `Number` оператор `+` склеїв би рядки `"14"` і `1` у `"141"`, а не додав би рік.

## 🎯 Практичне завдання

> ***Індекс маси тіла*** (***ІМТ***) показує, наскільки маса людини відповідає її зросту. Його рахують так: масу (`m`) в кілограмах ділять на зріст (`h`) у метрах, помножений сам на себе:
> 
> <p><i>ІМТ</i> = <i>m</i> / <i>h</i><sup>2</sup></p>
>
> Середня маса людини - близько `62`кг. Типовий зріст - `1.7`м.

В JavaScript ІМТ для людини з середніми параметрами можна порахувати так:

```javascript
let m = 62
let h = 1.7
let bmi = m / (h * h)
console.log("ІМТ:", bmi)
```

Зміни програму так, щоб масу і зріст запитували в користувача.

1. Замість сталих чисел використай `prompt`, щоб запитати масу в кілограмах і зріст у метрах.
2. Перетвори введені значення на числа за допомогою `Number`.
3. Покажи результат командою `alert` замісць `console.log` (`alert` може приймати тільки один аргумент - підпис і значення ІМТ потрібно поєднати в один рядок).

Щоб перевірити програму, можна ввести значення `62` і `1.7`. У вікні `alert` має з'явитися:
```
ІМТ: 21.453287197231838
```
