# Змінні - повторне використання значень

## 🧩 Теоретичний матеріал

Якщо значення потрібне кілька разів, змінна дозволяє записати його один раз і далі лише звертатися до значення за ім'ям:

***Приклад:***
```javascript
let a = 5
console.log("Сторона квадрата:", a)
console.log("Площа квадрата:", a * a)
```
***Результат у консолі:***
```
Сторона квадрата: 5
Площа квадрата: 25
```

Якщо довжина сторони зміниться, достатньо виправити `5` в одному місці - усі виведення, що використовують `a`, використають нове значення.

## 🎯 Практичне завдання

На координатній площині задано точку з координатами `(x, y)`. Порахуй відстань від початку координат `(0, 0)` до цієї точки.

```javascript
let x = 3
let y = 4

// ❗ порахуй та виведи відстань від початку координат до точки (x, y)

```

💡 Скористайся теоремою Піфагора і функцією `Math.sqrt`.

⚠️ Не рахуй результат вручну. Обов'язково використай змінні `x` та `y`.

Якщо `x` має значення `3`, а `y` - `4`, у консолі має з'явитися:
```
5
```
