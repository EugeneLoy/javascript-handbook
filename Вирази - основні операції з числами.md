# Вирази - основні операції з числами

## 🧩 Теоретичний матеріал

***Вираз*** - це запис, який ***обчислює*** значення. Вирази потрібні, щоб програма сама рахувала нові значення з уже наявних, замість того щоб розробник робив це вручну.

Арифметичні операції записують знаками `+` (додавання), `-` (віднімання), `*` (множення) і `/` (ділення). Ці знаки називають ***операторами***, а числа з обох боків від оператора - ***операндами***. Оператори й операнди разом утворюють вираз.

***Приклад:***
```javascript
console.log(20 + 15)
console.log(100 - 40)
console.log(40 * 2)
console.log(90 / 2)
```
***Результат у консолі:***
```
35
60
80
45
```

⚠️ У цих прикладах `console.log` отримує **один** аргумент-вираз. JavaScript спочатку обчислює вираз, а потім викликає `console.log`, що виводить отриманий аргумент.

## 🎯 Практичне завдання

У шкільній їдальні порція борщу коштує `40` грн. Порахуй, скільки заплатять за `3` порції.

Виведи результат однією командою `console.log`.

⚠️ Обов'язково використай вираз для обчислення, не рахуй результат вручну.

У консолі має з'явитися такий текст:
```
120
```
