# Теоретична частина

_Вираз_ - це запис, який JavaScript обчислює і отримує значення. Вирази потрібні, щоб програма сама рахувала нові значення з уже наявних, замість того щоб робити це вручну.

Арифметичні операції записують знаками `+` (додавання), `-` (віднімання), `*` (множення) і `/` (ділення). Ці знаки називають _операторами_ а числа з обох боків від оператора - _операндами_.

***Приклад:***
```javascript
console.log(35 + 15)
console.log(50 - 12)
console.log(4 * 3)
console.log(10 / 4)
```
***Результат у консолі:***
```
50
38
12
2.5
```

# Практичне завдання

У шкільній їдальні порція борщу коштує `40` грн. Порахуй, скільки заплатять за `3` порції.

Виведи результат однією командою `console.log` (обов'язково використай вираз для обчислення результату).

У консолі має з'явитися такий текст:

```
120
```
