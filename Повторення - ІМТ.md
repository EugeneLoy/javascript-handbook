# Повторення - ІМТ

## 💡 Повторення

| Приклад | Пояснення |
| --- | --- |
| `"Київ"` | рядок: текст у лапках |
| `"Привіт, " + "світе!"` | конкатенація: склеювання рядків |
| `7`, `3.14` | числа: без лапок, крапка в дійсних числах |
| `20 + 15`, `100 - 40`, `40 * 2`, `90 / 2` | арифметичні операції з числами |
| `(2 + 3) * 4` | дужки: спочатку те, що всередині |
| `console.log("Привіт")` | виведення одного значення в консоль |
| `console.log("Привіт,", "світе!")` | два аргументи: у консолі між ними буде пробіл |
| `alert("Привіт, світе!")` | виведення у спливаючому вікні браузера |
