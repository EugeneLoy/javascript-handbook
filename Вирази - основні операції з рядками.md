# Теоретична частина

Оператор `+` працює не лише з числами. Якщо операнди - рядки, JavaScript не додає їх, а _склеює_ в один текст. Таку операцію називають _конкатенацією_.

***Приклад:***
```javascript
console.log("Привіт, " + "Оля!")
```
***Результат у консолі:***
```
Привіт, Оля!
```

# Практичне завдання

Напиши програму, яка склеює назву предмета і номер уроку в один рядок.

Виведи результат однією командою `console.log`. Склей рядки `"Урок: "` і `"математика"`.

У консолі має з'явитися такий текст:

```
Урок: математика
```
