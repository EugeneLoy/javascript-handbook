# Теоретична частина

Оператор `+` працює не лише з числами. Якщо операнди - рядки, JavaScript не додає їх, а _склеює_ в один текст. Таку операцію називають _конкатенацією_.

***Приклад:***
```javascript
console.log("Привіт, " + "Оля!")
```
***Результат у консолі:***
```
Привіт, Оля!
```
