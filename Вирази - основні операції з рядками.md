# Вирази - основні операції з рядками

## 🧩 Теоретичний матеріал

Оператор `+` працює не лише з числами. Якщо операнди - рядки, JavaScript ***склеює*** їх в один текст. Таку операцію називають ***конкатенацією***.

Конкатенація потрібна, коли повідомлення складають із кількох готових рядків: привітання, назви, підписи.

***Приклад:***
```javascript
console.log("Привіт, " + "світе!")
```
***Результат у консолі:***
```
Привіт, світе!
```

## 🎯 Практичне завдання

Склей рядки `"тік"` і `"-ток"` в один рядок та виведи результат однією командою `console.log`.

⚠️ Обов'язково використай оператор `+`, не записуй готовий рядок `"тік-ток"` вручну.

У консолі має з'явитися такий текст:
```
тік-ток
```
