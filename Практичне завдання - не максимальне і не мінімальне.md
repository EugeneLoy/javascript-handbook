# Практичне завдання - не максимальне і не мінімальне

## 🧩 Теоретичний матеріал

Функція `Math.min` повертає ***найменше*** з переданих чисел. Функція `Math.max` повертає ***найбільше***.

У дужках можна записати ***кілька аргументів***, розділених комами. JavaScript порівняє всі ці числа і поверне одне значення.

***Приклад:***
```javascript
console.log(Math.min(5, 2))
console.log(Math.max(5, 2))
```
***Результат у консолі:***
```
2
5
```

З двома аргументами `Math.min` обирає менше число, а `Math.max` - більше.

Ті самі функції працюють і з трьома аргументами:

***Приклад:***
```javascript
console.log(Math.min(5, 2, 8))
console.log(Math.max(5, 2, 8))
```
***Результат у консолі:***
```
2
8
```

Результат виклику можна передати у `console.log` або як аргумент іншого виклику `Math.min` чи `Math.max`.

## 🎯 Практичне завдання

Задано три числа у змінних `a`, `b` і `c`. Потрібно знайти ***середнє за величиною***: те, що не є ні найменшим, ні найбільшим серед цих трьох.

Доповни стартовий код. Використай змінні `a`, `b` і `c` у виразі, щоб програма працювала **для будь-яких** їхніх значень, а не лише для `5`, `2` і `8`.

```javascript
let a = 5
let b = 2
let c = 8

// ❗ Порахуй та виведи значення, яке не є ні мінімальним, ні максимальним серед a, b і c.

```

⚠️ Не порівнюй числа вручну і не підставляй у виведення готове число.

Якщо `a` має значення `5`, `b` - `2`, а `c` - `8`, у консолі має з'явитися:
```
5
```

Якщо `a` має значення `1`, `b` - `9`, а `c` - `4`, у консолі має з'явитися:
```
4
```
