# Теоретична частина

Команда `console.log` виводить повідомлення в консоль. Її можна використати, щоб побачити результат роботи програми.

`console.log` пишеться малими літерами. Одразу після назви, у дужках, вказують значення, які потрібно вивести (такі значення називають _аргументами_).

***Приклад:***
```javascript
console.log("Привіт, світе!")
```
***Результат в консолі:***
```
Привіт, світе!
```

У цьому прикладі `console.log` отримує один аргумент - рядок `"Привіт, світе!"`. Коли JavaScript виконує цю команду, він виводить у консоль усе, що знаходиться в лапках.

## Виведення кількох значень
Можна вивести одразу кілька значень, якщо передати кілька аргументів. У такому випадку аргументи потрібно розділити комою, а у виведенні значення будуть розділені пробілами:
```javascript
console.log("Привіт,", "Оля!")
```
**Результат у консолі:**
```
Привіт, Оля!
```

# Практичне завдання

Напиши програму, яка виводить у консоль привітання для себе. Використай `console.log` і підстав своє ім'я замість прикладу.

Наприклад, у консолі повинно бути надруковано:
```
Привіт, Євген!
```
