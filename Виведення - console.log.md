# Виведення - `console.log`

## 🧩 Теоретичний матеріал

Команда `console.log` виводить повідомлення в консоль. Її можна використати, щоб побачити результат роботи програми.

`console.log` пишеться малими літерами. Одразу після цього, у дужках, вказують ***значення***, які потрібно вивести (такі значення називають ***аргументами***).

***Приклад:***
```javascript
console.log("Привіт, світе!")
```
***Результат у консолі:***
```
Привіт, світе!
```

У цьому прикладі `console.log` отримує один аргумент - рядок `"Привіт, світе!"`. Коли JavaScript виконує цю команду, він виводить у консоль усе, що знаходиться в лапках.

## 🎯 Практичне завдання

Напиши програму, яка виводить у консоль привітання для себе. Використай `console.log` і підстав своє ім'я замість прикладу.

Наприклад, у консолі повинно бути надруковано:
```
Привіт, Євген!
```
