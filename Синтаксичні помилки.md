# Теоретична частина

JavaScript має правила запису команд. Якщо їх порушити, програма навіть не почне виконуватися. Таку помилку називають _синтаксичною_.

Проаналізувавши повідомлення про помилку, можна знайти місце, де саме код записано неправильно.

***Приклад програми з помилкою:***
```javascript
console.log("Ця")
console.log("програма")
console.log("не"))
console.log("працює!")
```

Якщо запустити цю програму, у консолі з'явиться повідомлення про помилку:

```
Uncaught SyntaxError: Unexpected token ')'
    at https://code.loy.io/main.js:3:18
```

Це повідомлення можна прочитати так:

* `SyntaxError` означає, що помилка синтаксична: JavaScript не зрозумів запис команди.
* `Unexpected token ')'` означає, що зустрілась зайва дужка `)`.
* `main.js:3:18` вказує місце помилки: рядок `3`, позиція `18`.

Якщо прибрати зайву дужку (або, в данному випадку, видалити рядок `3`), програма запуститься.


# Практичне завдання

Виконай кроки нижче. Мета - навчитися знаходити синтаксичні помилки за повідомленням і виправляти їх.

1. Запусти програму з помилкою.

2. Проаналізуй повідомлення про помилку в консолі. Визнач, що саме пішло не так і де саме: номер рядка та позицію з частини на кшталт `main.js:3:18`.

3. Виправ помилку в коді і запусти програму знову. У консолі має з'явитися такий текст:

```
Ця
програма
працює!
```
