# Теоретична частина

Програми працюють з різними видами _значень_ (даних). Ці види називають _типами_. Типи потрібні, щоб JavaScript розумів, що перед ним: текст чи число, і як з цим значенням можна працювати.

Два базові типи - рядок і число.

## Рядок (`string`)

Рядок - це текст у лапках. Лапки можуть бути одинарні `'...'` або подвійні `"..."`. Для простого тексту обидва варіанти працюють однаково.

Рядки зручно використовувати для імен, назв і повідомлень.

***Приклад:***
```javascript
console.log("Привіт")
console.log('Київ')
```
***Результат у консолі:***
```
Привіт
Київ
```

## Число (`number`)

Число записують без лапок. У JavaScript і цілі, і дійсні числа мають один тип - `number`.

Ціле число не має дробової частини: `0`, `7`, `2026`. Дійсне число має дробову частину, яку відокремлюють крапкою: `3.14`, `0.5`.

Цілі числа зручні для підрахунку кількості. Дійсні - для вимірювань і часток.

***Приклад:***
```javascript
console.log(7)
console.log(3.14)
```
***Результат у консолі:***
```
7
3.14
```

# Практичне завдання

Напиши програму, яка виводить у консоль твоє улюблене число. Використай `console.log` і передай значення що має тип `number`, як аргумент (число, без лапок).

Наприклад, у консолі повинно бути надруковано:
```
42
```
