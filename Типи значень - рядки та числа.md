# Типи значень - рядки та числа

## 🧩 Теоретичний матеріал

Програми працюють з різними видами ***значень*** (даних). Ці види називають ***типами***. Типи потрібні, щоб JavaScript розумів, що перед ним: текст чи число, і як з цим значенням можна працювати.

Два базові типи - ***рядок*** і ***число***.

### Рядок (`string`)

Рядок - це текст у лапках. Лапки можуть бути одинарні `'...'` або подвійні `"..."`. Для простого тексту обидва варіанти працюють однаково.

Рядки зручно використовувати для імен, назв і повідомлень.

***Приклад:***
```javascript
console.log("Привіт")
console.log('Київ')
```
***Результат у консолі:***
```
Привіт
Київ
```

### Число (`number`)

Числа записують без лапок. У JavaScript і цілі, і дійсні числа мають один тип - `number`.

Ціле число не має дробової частини: `0`, `7`, `2026`. Дійсне число має дробову частину, яку відокремлюють крапкою: `3.14`, `0.5`.

Цілі числа зручні для підрахунку кількості. Дійсні - для вимірювань і часток.

***Приклад:***
```javascript
console.log(7)
console.log(3.14)
```
***Результат у консолі:***
```
7
3.14
```

⚠️ Якщо записати число в лапках, наприклад `"7"`, це вже буде рядок, а не число. Зовнішньо виведення може виглядати так само, але тип значення буде іншим.

## 🎯 Практичне завдання

Напиши програму, яка виводить у консоль твоє улюблене число.

⚠️ Запиши число без лапок, щоб тип був `number`, а не рядок.

Наприклад, у консолі може бути надруковано:
```
42
```
